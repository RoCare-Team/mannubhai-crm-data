Mannubhai Service Expert - PAN India Franchise CRM (core version)

HOW TO RUN
1. Unzip the folder.
2. Double-click index.html. It opens in Chrome, Edge or Firefox.
3. An internet connection is needed once per load for the chart library (Chart.js from cdn.jsdelivr.net).

LOGIN (setup logins)
admin / Mannubhai@2026       (Super Admin, can edit)
management / Mannubhai@2026  (view only)
accounts / Mannubhai@2026    (view only)
Change these in the USERS line near the top of the script in index.html before real use.
These logins are for demonstration only and are NOT secure.

DATA
- 180 locations (30 original + 150 planning cities), all start as "Proposed".
- Revenue figures are editable planning inputs, not actual company results.
- Data is saved in this browser only (localStorage). A real database is a later step.

TO REPLACE WITH REAL DATA
